# Flujo del Comando `/sugerencias`

## Objetivo

Generar propuestas accionables basadas en el estado real del repo, no en documentación antigua.

## Workflow

1. Revisar cambios recientes y estado actual del código.
2. Contrastar con `memory_logs.md`, `tasks.md` y arquitectura viva.
3. Producir sugerencias separadas por horizonte:
   - corto plazo,
   - mediano plazo,
   - largo plazo.
4. Si una sugerencia cambia el backlog real, reflejarla también en `tasks.md`.
