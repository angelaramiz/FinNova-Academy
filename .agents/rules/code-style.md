# Reglas de Estilo de Código

1. TypeScript estricto por defecto.
2. Evitar `any` nuevo salvo límite real de librería o payload externo.
3. Mantener imports ordenados y sin churn innecesario.
4. Preservar comentarios útiles existentes.
5. Seguir la estética dark/glass/teal-indigo ya presente en web.
6. En Compose, mantener consistencia con el tema actual del módulo Android.
