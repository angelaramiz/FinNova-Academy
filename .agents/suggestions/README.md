# Sugerencias

Esta carpeta guarda recomendaciones no ejecutadas todavía.

Convención:

- un archivo por fecha,
- sugerencias separadas en corto, mediano y largo plazo,
- solo registrar propuestas que sigan vigentes tras revisar el estado real del repo.

Si una sugerencia pasa a trabajo comprometido, debe reflejarse también en `tasks.md`.
En esta carpeta se guardarán los reportes estratégicos sugeridos por el agente a corto, mediano y largo plazo.

## Formato del Reporte
Cada reporte se creará como `YYYY-MM-DD-sugerencias.md` y contendrá:
*   **Diagnóstico de la Base de Código**: Qué áreas del código presentan fricciones de mantenimiento o deuda técnica.
*   **Propuestas de Mejora**:
    *   **Corto Plazo**: Mejoras rápidas y de bajo esfuerzo (ej. tipos TypeScript, control de estados de carga).
    *   **Mediano Plazo**: Mejoras estructurales medianas (ej. modularización de vistas complejas).
    *   **Largo Plazo**: Mejoras de arquitectura mayor (ej. cambio a base de datos física, flujo de despliegue).
*   **Justificación e Impacto**: Relación de los cambios propuestos con el objetivo principal del proyecto.
